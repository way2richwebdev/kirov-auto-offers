# Лендинги автомастерских Кирова

Три самостоятельных демонстрационных сайта, подготовленных для предложения услуг веб-разработки. Это не официальные сайты организаций.

## Страницы

- `formula-avto.html` — Формула Авто
- `leotech.html` — ЛеоТех
- `atmosfera.html` — Атмосфера

## Сборка

Только Node.js, без зависимостей:

```sh
node build.mjs
node check.mjs
```

Сборка создаёт каталог `dist`. Содержимое `dist` размещено в корне репозитория. GitHub Pages использует ветку `main`, каталог `/ (root)`. Для обновления выполните сборку и скопируйте полученные файлы из `dist` в корень.

## Поведение

- Адаптивная сетка и мобильное меню.
- Фильтрация услуг по категориям.
- Выбор услуги переносит её в форму записи.
- Форма создаёт текст для WhatsApp, но не отправляет его автоматически.
- Данные формы не сохраняются. Бэкенда и аналитики нет.
- Интерактивные Яндекс Карты с отметками точных координат и кнопками маршрута.
- SVG-иллюстрация авторская, без фотографии, выдаваемой за реальную мастерскую.
- Страницы закрыты от поисковой индексации через `noindex,nofollow` и `robots.txt`, так как это предпросмотр.

## Публикация

1. Создать публичный репозиторий `kirov-auto-offers`.
2. Загрузить исходники и содержимое `dist` в корень.
3. Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
4. Проверить готовую публикацию и три URL.

Настройка не требует платных сервисов, ключей или серверного приложения.
